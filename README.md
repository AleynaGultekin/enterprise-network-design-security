# 🌐 Enterprise Network Infrastructure Design & Security

A comprehensive enterprise network simulation built in **Cisco Packet Tracer**, demonstrating robust multi-VLAN architecture, secure routing, and endpoint protection.

## 📌 Project Overview
This project models a multi-department enterprise network using a hierarchical Core-Access model. It enforces strict network segmentation, secure access control lists (ACLs), and port security policies to prevent unauthorized access.

## ⚙️ Architecture & Security Features
- **4-VLAN Enterprise Design:** Segmented network architecture separating different departments and traffic types.
- **Inter-VLAN Routing:** Configured routing mechanisms to enable controlled communication across different VLANs.
- **Guest Network Isolation:** Implemented extended Access Control Lists (ACLs) to isolate guest traffic and secure internal resources.
- **Port Security:** Configured sticky-MAC address binding on switch ports to restrict physical access and mitigate MAC spoofing attacks.
- **Connectivity Verification:** Rigorously tested and verified end-to-end network reliability using ICMP (Ping) protocols.

## 💻 Tech Stack & Tools
- **Simulation Tool:** Cisco Packet Tracer
- **Protocols & Concepts:** VLANs, Inter-VLAN Routing, Extended ACLs, Port Security (Sticky MAC), ICMP
